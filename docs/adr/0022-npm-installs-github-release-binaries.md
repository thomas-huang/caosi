# npm package includes platform binaries

Users must not need a Go toolchain. The documented install is `npm install -g @thomas-huang/caosi`. Unscoped `caosi` was rejected by the npm registry as too similar to an existing package; the CLI binary remains `caosi`. The npm tarball contains all shipped platform binaries (macOS, Linux, Windows amd64, each amd64/arm64 where we ship); the wrapper selects one. Downloading a binary from GitHub Releases on postinstall was reversed: it required install scripts (`allowScripts`) and failed when GitHub was unreachable. Per-platform optional npm packages remain too much publish surface. GitHub Releases still hold the same assets for users without Node. Homebrew, Scoop, and WinGet are not the first-class path; Bun consumes the same npm package. `go install` stays a contributor path, not the user path.
