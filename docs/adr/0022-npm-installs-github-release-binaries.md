# npm installs GitHub Release binaries

Users must not need a Go toolchain. The documented install is `npm install -g @thomas-huang/caosi`. Unscoped `caosi` was rejected by the npm registry as too similar to an existing package; the CLI binary remains `caosi`. Platform binaries (macOS, Linux, Windows amd64, each amd64/arm64 where we ship) live on GitHub Releases with checksums; the npm package is a thin installer that downloads the matching asset on postinstall. Embedding every binary in the npm tarball was rejected because unrelated platforms pay the download. Per-platform optional npm packages were rejected as too much publish surface. Homebrew, Scoop, and WinGet are not the first-class path; Bun consumes the same npm package. `go install` stays a contributor path, not the user path.
